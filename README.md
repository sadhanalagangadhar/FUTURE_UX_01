# FUTURE\_UX\_01 — NeatNest Cleaning Website Redesign

**Track:** UI/UX Design (UX)  
**Task:** 1 — Local Service Business Website Redesign  
**Concept business:** NeatNest Cleaning (fictional portfolio concept)  
**Tool:** HTML + CSS + vanilla JavaScript

## Project overview

NeatNest is a premium-modern concept for a local home-cleaning service. The design focuses on clear service positioning, trust, straightforward navigation, and lead generation.

## Pages

* `index.html` — Homepage with value proposition, service overview, trust elements, and calls to action.
* `services.html` — Service details for regular cleaning, deep cleaning, and move-in/move-out cleaning.
* `contact.html` — Quote enquiry form and contact information.
* `styles.css` — Responsive design system and page styling.
* `script.js` — Mobile navigation and client-side demo form confirmation.

## UX and conversion rationale

1. **Clear value proposition:** The homepage headline and supporting copy explain the benefit before asking visitors to act.
2. **Visible calls to action:** “Get a free quote” appears in the header and in key page sections, reducing the effort required to enquire.
3. **Service clarity:** Three service types are separated into scannable cards and detail sections so users can find a relevant option quickly.
4. **Trust before conversion:** The design highlights communication, clear quotes, and respectful care to reduce uncertainty.
5. **Short, structured form:** The contact page asks for the minimum information needed to understand the enquiry, with labels, required fields, and clear feedback.
6. **Responsive layout:** CSS breakpoints adapt navigation, cards, forms, and content layouts for smaller screens.
7. **Accessibility basics:** Semantic HTML, descriptive image alt text, visible focus states, form labels, and a live status message are included.

## Important prototype limitations

* NeatNest is a fictional concept, not a real company.
* The email and service area are placeholders and must not be represented as verified business details.
* The quote form is a front-end demonstration only. It does **not** send, store, or email submissions.
* Photos are loaded from Unsplash URLs and therefore require an internet connection.
